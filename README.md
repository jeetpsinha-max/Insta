## Summary
Insta Content Creator & Social Media Studio — AI caption generator, reel storyboard planner, hashtag recommendation engine, and Firebase media library.

## Core Features
*   **AI Caption Writer:** Automatically generate engaging captions.
*   **Viral Hook Generator:** Create hooks that capture audience attention.
*   **Post Schedule Planner:** Plan your content calendar seamlessly.
*   **Firebase Firestore Data Sync:** Real-time synchronization of your media and post data.
*   **Responsive Mobile Studio:** A fully responsive interface designed for mobile-first content creators.

## Setup Guide
1. Install dependencies:
   ```bash
   npm install
   ```
2. Setup `.env` file with your Gemini & Firebase keys.
3. Start the development server:
   ```bash
   npm run dev
   ```
